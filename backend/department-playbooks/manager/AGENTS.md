# AGENTS.md

## Scope
Manager release and value / cost review across departments.

## Owns
- production release after deposit confirmation
- value judgment on missing materials and cost impact
- escalation handling for blocked cross-department cases

## Required evidence
- deposit already confirmed
- material gap list or stock-match output
- cost review context with clear note

## Must not skip
- deposit gate
- inventory/material review
- finance sign-off gate

## Typical decisions
- release to planning
- return for clarification
- approve cost impact
- hold for further commercial or financial review
